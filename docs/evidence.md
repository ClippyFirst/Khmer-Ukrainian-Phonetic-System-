# Evidence and provenance

## Primary sources currently encoded
1. Unicode Standard 17.0.0, Chapter 16 — authoritative encoding and structural script description.
2. Chem & Chem (2020), The Standard Khmer vowel system: An acoustic study — Phnom Penh-oriented acoustic evidence.
3. Henderson (1952), The Main features of Cambodian Pronunciation — foundational historical register analysis.
4. Wayland et al., work on Phnom Penh Khmer — contemporary phonetic evidence.

## Source hierarchy
1. peer-reviewed experimental phonetics/phonology
2. specialist grammars and monographs
3. Unicode Standard for encoding/script structure
4. authoritative dictionaries/corpora
5. established standards
6. university/educational material
7. general web explanations

A lower-level source cannot silently override a higher-level source.
