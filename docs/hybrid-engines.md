# Кандидатний гібридний IPA-шар Khmer

HybridKhmerEngine запускає чинний детермінований RuleBasedKhmerEngine і за конфігурацією збирає зовнішні IPA-кандидати. Зовнішні джерела не замінюють правила автоматично.


Зовнішні провайдери **не завантажуються й не запускаються автоматично**. Виклик `HybridKhmerEngine()` без аргументу `providers` запускає лише внутрішні правила та повертає порожній список зовнішніх кандидатів. Щоб запустити конкретні зовнішні рушії, їх потрібно явно передати в словник `providers` після локального встановлення/підготовки залежностей і перевірки прав. Це не змінює поведінку опублікованого сайту та не запускає мережеві завантаження під час звичайного аналізу.

## Підключення

```python
from khmer_ua import HybridKhmerEngine, make_mekongphon_backend, make_command_backend
engine = HybridKhmerEngine({
    "mekongphon": make_mekongphon_backend(),
    # Goruut / Khmer Phonemizer / Epitran can be supplied via pinned CLI wrapper.
})
result = engine.analyze("ខ្មែរ")
```

Кандидати повертаються в external_candidates із сирим IPA та provenance. Фінальне ipa залишається результатом внутрішнього детермінованого рушія. Голосування не використовується.

## Бенчмарки та рішення

- MekongPhon: 100/100 виходів; 64/100 збіги з source-attested pron_no_tones, CER 12.539%; незалежне gold = 0. Не перевіряє тон/фонацію; незалежність split не встановлена.
- Khmer Phonemizer: 100/100 виходів; 18/100 строгих збігів у тому самому діагностичному наборі; independent gold = 0.
- Goruut: попередній 100-рядковий прогін: 97 виходів, 6/100 строгих збігів, 27 частково неперекладених фрагментів; відсутній upstream asset weights9.bin.zlib.
- Khmer acoustic-model dictionary: BLOCKED — повний файл відсутній, кількість записів і ліцензійні декларації суперечливі.

Це source concordance, не accuracy. MekongPhon — найкращий кандидат для подальшого benchmark-порівняння, але не підтверджений замінник Phnom Penh rule engine.

## Пріоритети провайдерів

Нижче число означає лише порядок запуску й показу кандидатів (менше = раніше), а не доведену якість і не право замінити фінальне IPA:

1. **MekongPhon (10)** — перший зовнішній кандидат для дослідження: найкраща поточна source-concordance (64/100), але незалежний gold = 0, split independence і тон/фонація не підтверджені.
2. **Khmer Phonemizer (20)** — незалежний контрольний comparator (18/100), не fallback.
3. **Epitran (30)** — низькопріоритетний сегментний контроль; не вважати повною Khmer phonology без профільної валідації.
4. **Goruut (90)** — останній діагностичний кандидат; низька concordance та відсутній upstream weights asset.
5. Невідомі провайдери (50) — між контрольним і низькопріоритетним рівнями, доки не внесені до реєстру.

Фінальний вихід і далі визначає внутрішній правиловий рушій. Для майбутнього підвищення пріоритету потрібні незалежні Phnom Penh IPA gold, train/test disjointness, повна перевірка голосних/довготи/код/фонації та відтворювані тести.
