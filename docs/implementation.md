# Implementation\n\n## Package\n\nThe package is khmer_ua, with a CLI entry point khmer-ua.\n\n## Data flow\n\nnormalize.py performs Unicode NFC normalization.\n\nparser.py performs conservative orthographic decomposition into consonants, coeng/subscripts, vowel signs and independent vowels.\n\nphonology.py resolves structural register/inherent-vowel metadata without inventing IPA.\n\nipa.py applies pronunciation-profile transformations to already established IPA. It is intentionally not an orthography-to-IPA oracle.\n\npractical.py reads the canonical data/ukrainian/practical-policy.json target policy and maps IPA segments to the proposed Ukrainian practical layer.\n\nThe static browser adapter in src/main.js consumes the same canonical Khmer/Ukrainian data files and a small provenance-bearing fixture set. It must not maintain a second authoritative linguistic table.\n\n## Determinism\n\nThe implementation is deterministic and dependency-free at runtime. Linguistic uncertainty is represented as status/limitations rather than random or probabilistic output.\n\n## Web build\n\nThe web layer is built with Vite. npm run check performs structural regression checks and npm run build produces the static dist/ artifact used by GitHub Pages.\n\nThe browser service deliberately returns NOT_ESTABLISHED / EVIDENCE_LIMITED for inputs outside the implemented, provenance-bearing examples. This is a correctness boundary: the project must not fabricate IPA.\n\n## API\n\n    from khmer_ua import analyse, render_ipa_profile, map_sequence\n    result = analyse("ខ្មែរ")\n    ipa = render_ipa_profile("krɑː", "careful_standard")\n    ua = map_sequence(["kʰ", "a"])\n\nThe example IPA is illustrative of the API and must not be read as a claim that the parser currently derives that IPA automatically.\n\n## CLI\n\nkhmer-ua analyse TEXT\nkhmer-ua syllables TEXT\nkhmer-ua ipa TEXT\nkhmer-ua transliterate TEXT\n\nAt present the ipa command prints NOT ESTABLISHED when no IPA engine result exists. Other placeholder commands must not be presented as complete generators.
